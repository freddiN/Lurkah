simple android app to browse imgurs most viral

features:
- display media type (image, video, album) and filesize before playing it (looking at you, 175 MB MP4!)
- pull to refresh
- block accounts from showing up in the list
- darkmode
- double tap to zoom images
- swipe left/right to navigate the feed
- configure video autoplay (start when opening) and replay (loop)
- optionally display comments
- new setting to move the buttons to the bottom
