simple android app to browse imgurs most viral

features:
- display media type (image, video) and filesize before playing it (looking at you, 175 MB MP4!)
- pull to refresh
- block accounts from showing up in the list
- block tags
- darkmode
- tapto display video player controls
- double tap to zoom for videos and images
- swipe left/right to navigate the list from the details
- configure video autoplay (starts when opening) and replay (loop videos)
